# Project Specs

## What it is

Pure Dart library for encoding and decoding color palette file formats.

## Main technologies

Dart with Flutter tooling, binary and document parsing with code-generated models.

## Main structure

- `lib/` -> public codec API for palette formats.
- `example/` -> demo app showing library usage.
- `test/` -> automated tests for format coverage.
- `scripts/` -> automation for package tasks.
- `docs/` -> project documentation including the supported formats reference.
